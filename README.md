# DelfiASale

Примерно Android приложение (Java) за продажби с три основни секции на началния екран:

- **Касова бележка** – показва добавените артикули, количество и сума.
- **Групи** – зареждат се от REST API.
- **Стоки** – филтрирани по избраната група; при избиране добавят продукт към бележката.

## REST API очаквания
- `GET /groups` → списък с групи (`id`, `name`).
- `GET /groups/{groupId}/items` → артикули в група (`id`, `group_id`, `name`, `price`, `barcode`).
- `POST /sales` → изпраща продажбата. Форматът се описва от `SaleRequest` (списък от артикули с barcode, quantity, price).

За да стартирате реално приложение, задайте коректен `BASE_URL` в `ApiClient` и добавете необходимите Android и Gradle инструменти.
